# Trento Parking Bot
Parking bot for the cities of Trento and Bolzano. This bot was implemented as part of the project for the course of Service Design and Engineering.

## How this works?
This bot uses the user's location for searching, inside a two-kilometer radius, a parking spot for your car/vehicle only in the cities of Trento and Bolzano. Below you can find a list of the commands available in the bot:
+ /start : starts the interaction with the Bot;
+ /findparkingtn : find a parking spot within a 2km radius based on the location provided by the user in the city of Trento;
+ /findparkingbz : find a parking spot within a 2km radius based on the location provided by the user in the city of Bolzano;
+ /help : prints out the list of all available commands with the correct explanation, and how to use it based on several examples;
+ /stop : stops the interaction with the Bot.
